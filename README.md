# nohapp-brand

Brand assets for nohapp!: the "no👍app!" wordmark and app icons.

## logos/

| File | Use |
|---|---|
| `nohapp-logo-light-color.svg` | White lettering, yellow hand and wave, on turquoise `#14ACBF` |
| `nohapp-logo-light-mono.svg` | Navy `#0B3B4A` on sand `#FFF6E0` |
| `nohapp-logo-dark-color.svg` | Teal `#2EC4D6` lettering, yellow hand and wave, on navy `#0A2A33` |
| `nohapp-logo-dark-mono.svg` | Sand `#FFF6E0` on navy `#0A2A33` |

All logos are 1200×600 vectors with the lettering converted to outlines (font: Fredoka SemiBold, SIL Open Font License), so no font install is needed.
